[프로젝트 개요]
Streamlit 기반의 푸드뱅크 통합 관리 웹 애플리케이션을 개발해줘. 이 시스템은 다수의 사용자가 동시 접속하며, Firebase(또는 Supabase)를 연동하여 실시간으로 데이터를 읽고 써야 해. 데스크톱과 모바일 환경을 모두 지원하는 반응형 UI로 구성해줘.

[1. 로그인 및 사용자 권한 라우팅 (RBAC)]
접속 시 아이디/비밀번호 기반의 로그인 화면을 제공하고, 사용자 Role에 따라 각기 다른 대시보드로 자동 라우팅되도록 st.session_state를 설정해줘.

관리자 (사회복지사, 3명 이상): 모든 페이지 접근 가능. PC 기반 전체 통계 및 관리.

현장운영 (사회복무요원, 2명 이상): PC/모바일 겸용. 엑셀 마감 및 POS(결제) 기능 특화.

재고관리 (자활근무자, 5명 이상): 모바일 특화. 재고 실사 기능.

[2. 화면별 세부 기능 요구사항]

A. 관리자 모드 (사회복지사 전용)

오늘의 총 입출고 현황, 이용자 방문 통계, 재고 부족 알림 등을 차트와 요약표로 한눈에 보는 통합 대시보드.

사용자 계정 생성 및 권한 부여 관리 페이지.

B. 현장운영 모드 (사회복무요원 전용 - 극강의 빠른 UI)

자동화 엑셀 마감: 아침 통계/입출고 엑셀을 업로드하면 즉시 가공해 다운로드하는 기능 포함.

웹 POS 시스템 (바코드 스캔): > * 바코드 리더기로 물품을 찍으면 즉시 리스트에 추가되는 텍스트 입력창(자동 포커스 기능 포함).

[규칙 검증 로직]: 스캔된 물품이 '기본 5개 품목' 규칙에 맞는지 즉각적인 시각적 피드백(초록/빨강 알림) 제공.

[특이사항 예외 처리]: 당일 방문 이용자의 속성(예: 한부모 가정, 반지하 거주 등)을 체크박스나 드롭다운으로 빠르게 선택. 선택 시 추가 제공 가능한 '서비스 물품' 쿼터가 시스템에 임시로 승인되도록 로직 구성.

C. 모바일 재고관리 모드 (자활근무자 전용)

모바일 브라우저 세로 화면에 최적화된 큰 폰트와 터치 버튼 형태의 UI 적용.

자신의 로그인 ID가 기록되어 누가 재고를 조사했는지 로그(Log)를 남길 것.

화면 상단에 [구역1], [구역2], [구역3] 버튼을 두어 현재 실사 중인 장소를 선택.

목록에 FMS 원데이터(전산 대조) 수량을 보여주고, 바로 옆에 '+', '-' 버튼을 두어 실제 매대 수량을 직관적으로 매칭 및 수정할 수 있는 기능. 불일치 시 붉은색으로 강조.
